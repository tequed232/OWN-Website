# OWN-Website

A personal portfolio and developer hub built around a Swiss International Typographic Style information system and restrained Constructivist geometry.

> Less decoration. More information. Stronger structure.

## Product direction

- Editorial, grid-based layout with disciplined typography and whitespace.
- Seven original geometric Arcana cards for section navigation.
- Scroll-driven card reveal; theme changes only after explicit user selection.
- Real GitHub repository and contribution data, fetched server-side.
- Config-driven social links and featured projects—no fabricated metrics.
- Light and dark themes, responsive layouts, and reduced-motion support.
- Deployment targets: Vercel and self-hosted Node.js.
